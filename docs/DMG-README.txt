HoverFocus 0.1.1
════════════════════════════════════════════

鼠标悬停到窗口，键盘焦点就切过去 —— 不用点击。
Hover 到哪个窗口，键盘输入就跟到哪个窗口。默认不改变窗口叠放顺序。

安装
────
1. 把 HoverFocus.app 拖进「应用程序」
2. 双击启动

不需要授予任何权限，装完即用。

如果想提高命中精度（窗口重叠、圆角、阴影场景）
菜单栏图标 → 授予辅助功能权限 → 系统设置 → 隐私与安全性 → 辅助功能 → 勾选
这是可选的，不授权分屏场景也完全准确。

常见问题
────
Q 菜单栏没出现图标？
  跑一次自检看它到底有没有起来：
  /Applications/HoverFocus.app/Contents/MacOS/HoverFocus --selftest
  输出里看 statusItemCreated 和 buttonWindowVisible。

Q 悬停没反应？
  菜单栏图标 → 诊断信息 → 看「忽略原因计数」。
  每个忽略原因都有中文解释和累计次数，一眼能看出被哪道守卫挡了。

Q 某些 App 不想被抢焦点？
  鼠标停在它上面 → 点菜单栏图标 → 排除『它』。

关于 Gatekeeper
────
这个包用自签证书签名，不是 Apple Developer ID。
首次打开如果提示「无法验证开发者」，右键点 HoverFocus.app → 打开 → 再确认一次。
这是自签分发的固有限制，不是程序问题。
